Binomial Distribution / Key Concepts

Understand why.
Then solve the question.

Start with a reason, connect it to a key idea, study a worked example, then try a similar exercise.

Why do we need a Binomial model? With 3 tosses we can list 8 orders. With 10 tosses there are 1,024 orders. If the question only asks how many heads, the Binomial formula groups the matching orders and adds their probabilities efficiently.
Key concept 1 / 5

1 · What are we counting, and when is it Binomial?

Why?

The model must match what X counts. A fixed n gives a known number of positions. Independence allows multiplication, and a common p makes orders with the same success count equally likely. These conditions let one Binomial formula group the orders correctly.

Key idea

Use X ∼ Bin(n, p) when there are a fixed n trials, two outcomes per trial, independent trials, and the same success probability p. X counts successes, so X = 0, 1, …, n.

Worked example

Three independent tosses, with P(H) = 0.6. Let X count heads.

  1. Define the counted outcome: success = H, so p = 0.6.
  2. There are n = 3 independent trials; each gives H or T, with unchanged probabilities.
  3. Therefore X ∼ Bin(3, 0.6), with possible counts 0, 1, 2, 3.
X ∼ Bin(3, 0.6)

Watch out: Before using the formula, check independence and match p to what X counts.
Key concept 2 / 5

2 · Why multiply along one order?

Why?

HHT means all three specified results occur: first H AND second H AND third T. Independence means earlier results do not change the probabilities of later results, so the probability of this joint event is a product.

Key idea

For one specified order, multiply one factor p for each success and one factor 1 − p for each failure. With k successes in n trials, the result is pᵏ(1 − p)ⁿ⁻ᵏ.

Worked example

Find the probability of the exact order HHT.

  1. First H: probability 0.6. Second H: probability 0.6. Third T: probability 0.4.
  2. Multiply because all three results are required and the tosses are independent.
  3. 0.6 × 0.6 × 0.4 = 0.144. This is one order only.
P(HHT) = 0.6² × 0.4 = 0.144

Your turn

What is the probability of the exact order HTT?
Watch out: A probability for one exact order is different from a probability for a head count.
Key concept 3 / 5

3 · Why does the combination number appear?

Why?

“Exactly two heads” allows HHT OR HTH OR THH. These orders cannot occur together in the same experiment, so their probabilities add. Each has the same number of H and T factors, so they have equal probabilities. Adding equal terms becomes multiplication by the number of orders.

Key idea

C(n,k) counts the ways to choose the k success positions among n positions. Therefore P(X = k) = C(n,k)pᵏ(1 − p)ⁿ⁻ᵏ, for k = 0, 1, …, n.

Worked example

For X ∼ Bin(3, 0.6), find P(X = 2).

  1. The matching orders are HHT, HTH and THH: C(3,2) = 3.
  2. Each order has probability 0.6² × 0.4 = 0.144.
  3. Add the three mutually exclusive cases: 0.144 + 0.144 + 0.144 = 3 × 0.144 = 0.432.
C(n,k) = n! / [k!(n − k)!] · 0! = 1

Your turn

Four independent tosses have P(H) = 0.6. What is the probability of exactly three heads?
Watch out: C(n,k) counts possible orders. It is not the number of repeated experiments.
Key concept 4 / 5

4 · Why translate the words before calculating?

Why?

The formula gives the probability of one count k. Wording such as “at least” selects several possible counts. We must decide which integers belong to the event before adding probabilities. A complement can replace a long sum with a shorter calculation.

Key idea

Exactly r: X = r. At most r: X ≤ r. At least r: X ≥ r. More than r: X > r, or X ≥ r + 1 for integer counts. The complement of X ≥ r is X ≤ r − 1.

Worked example

For X ∼ Bin(3, 0.6), find the probability of at least one head.

  1. At least one means X ∈ {1, 2, 3}.
  2. The only excluded count is X = 0: all three tosses are tails. Its probability is 0.4³ = 0.064.
  3. Use total probability 1: P(X ≥ 1) = 1 − P(X = 0) = 1 − 0.064 = 0.936.
P(X ≥ 1) = 1 − P(X = 0) = 0.936

Your turn

For X ∼ Bin(3, 0.6), “more than one head” includes which counts, and what is its probability?
Watch out: At least one and more than one are different events. List the included integers.
Key concept 5 / 5

5 · Why can the mean be a non-integer?

Why?

Each trial contributes either 1 for success or 0 for failure. Its expected contribution is 1 × p + 0 × (1 − p) = p. Adding n expected contributions gives np. Each trial has variance p(1 − p); independent trials let these variances add.

Key idea

For X ∼ Bin(n, p), E(X) = np, Var(X) = np(1 − p), and SD(X) = √[np(1 − p)]. A mean describes an average count; it need not be a possible outcome of one experiment.

Worked example

For X ∼ Bin(3, 0.6), find the mean, variance and standard deviation.

  1. Mean: E(X) = 3 × 0.6 = 1.8 heads per three-toss experiment on average.
  2. Variance: Var(X) = 3 × 0.6 × 0.4 = 0.72.
  3. Standard deviation: SD(X) = √0.72 ≈ 0.8485. An individual head count is still 0, 1, 2 or 3.
E(X) = 1.8 · Var(X) = 0.72 · SD(X) ≈ 0.8485

Your turn

For Y ∼ Bin(10, 0.6), what are the mean and variance?
Watch out: Mean, variance and standard deviation describe different quantities. Do not use np for all three.

Put the story into a formula.

X ∼ Pois(λ)

λ is the expected number of arrivals in the chosen interval. Here λ = rate × 1 hour.

P(X = k) = e−λ λk / k!

k is a whole-number count: 0, 1, 2, … . Unlike three coin tosses, there is no fixed maximum number of customers in the model.

3Use the formula, one step at a time

Exactly 3 customers in an hour

1 · Define X. X counts customers arriving during one hour.

2 · State the model. Under the stated Poisson arrival assumptions, λ = (4 customers/hour)(1 hour) = 4, so X ∼ Pois(4).

3 · Translate. “Exactly 3” means X = 3.

4 · Substitute. P(X = 3) = e−4 × 4³ / 3!
= e−4 × 64 / 6 ≈ 0.1954.

5 · Interpret. About 19.54% of hours would have exactly 3 arrivals in the long run, under this model.

What about no customers?

P(X = 0) = e−4 × 4⁰ / 0! = e−4 ≈ 0.0183. Zero is a valid count. Remember 4⁰ = 1 and 0! = 1.
